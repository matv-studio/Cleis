## Cleis 0.2.0

First version of Cleis: a password manager and contact book for personal and team use, with an
optional organization server.

### Downloads
- **Windows** — `Cleis-0.2.0-…-windows-x64-portable.zip`: unzip and run `Cleis.exe`. The zip also
  holds `cleis-server.exe` (organization server) and its guide (`SERVER.md`). The program is not
  signed yet: Windows SmartScreen may ask for confirmation on first launch.
- **Linux server** — `cleis-server-0.2.0-…-linux-x64.tar.gz`, with the Docker and service files.
- Each file comes with its `.sha256` checksum.
- macOS: not built for this version (no Apple signing yet).

### What it does
- **Vault**: items with passwords, 2FA codes, prices and custom columns (formulas, choices, dates),
  folders, favorites, history, trash; table and card views; import from CSV (Bitwarden,
  1Password, Chrome, Firefox, Notion, Excel…); health report (weak, reused, old passwords, no 2FA).
- **Contacts**: contact book with labels, folders, linked items, duplicate merge, vCard.
- **Autofill** (Windows): global shortcuts, Quick Access, filling of the window in front.
- **Security**: Argon2id + AES-256-GCM, master password, optional code at opening with recovery
  codes, lock after inactivity, clipboard cleared, emergency kit (PDF).
- **Sync and backups**: a folder (OneDrive, Google Drive, network share), a private GitHub
  repository or SFTP; dated backups; restore at first launch.
- **Organization**: shared spaces encrypted end-to-end or Standard, roles and Super Admin, members
  and invitations (also by e-mail), two-step verification (authenticator app, e-mail, SMS,
  Google, Microsoft), signed and chained activity log, re-encryption, server backups. The server
  can run on the admin's computer, started from Cleis, or as a service (Linux, Windows, macOS,
  Docker). Several organizations per vault, one tab each.
- **Interface** in English and French (the system's language at first launch; Preferences ›
  Language).

### Known limits
- Not yet tried on real services: SMTP mail, SMS gateway, Google / Microsoft sign-in, Windows
  service installed from Program Files.
- Amounts keep the `€69.99` form in French.

## Cleis 0.2.0 (français)

Première version de Cleis : gestionnaire de mots de passe et carnet de contacts, pour soi et pour
une équipe, avec un serveur d'organisation facultatif.

### Téléchargements
- **Windows** — `Cleis-0.2.0-…-windows-x64-portable.zip` : décompresser et lancer `Cleis.exe`. Le
  zip contient aussi `cleis-server.exe` (serveur d'organisation) et son guide (`SERVER.md`). Le
  programme n'est pas encore signé : SmartScreen peut demander une confirmation au premier
  lancement.
- **Serveur Linux** — `cleis-server-0.2.0-…-linux-x64.tar.gz`, avec les fichiers Docker et de
  service.
- Chaque fichier a sa somme de contrôle `.sha256`.
- macOS : pas construit pour cette version (pas encore de signature Apple).

### Fonctions
- **Coffre** : éléments avec mots de passe, codes 2FA, prix et colonnes personnalisées (formules,
  choix, dates), dossiers, favoris, historique, corbeille ; vues tableau et cartes ; import CSV
  (Bitwarden, 1Password, Chrome, Firefox, Notion, Excel…) ; rapport de santé (mots de passe
  faibles, réutilisés, anciens, sans 2FA).
- **Contacts** : carnet avec étiquettes, dossiers, éléments liés, fusion des doublons, vCard.
- **Remplissage** (Windows) : raccourcis globaux, Accès rapide, remplissage de la fenêtre au
  premier plan.
- **Sécurité** : Argon2id + AES-256-GCM, mot de passe maître, code à l'ouverture facultatif avec
  codes de secours, verrouillage après inactivité, presse-papiers vidé, kit d'urgence (PDF).
- **Synchronisation et sauvegardes** : un dossier (OneDrive, Google Drive, partage réseau), un dépôt
  GitHub privé ou SFTP ; sauvegardes datées ; restauration au premier lancement.
- **Organisation** : espaces partagés chiffrés de bout en bout ou Standard, rôles et Super Admin,
  membres et invitations (aussi par e-mail), vérification en deux étapes (appli
  d'authentification, e-mail, SMS, Google, Microsoft), journal d'activité signé et chaîné,
  rechiffrement, sauvegardes du serveur. Le serveur tourne sur l'ordinateur de l'admin, lancé par
  Cleis, ou comme service (Linux, Windows, macOS, Docker). Plusieurs organisations par coffre, un
  onglet chacune.
- **Interface** en anglais et en français (langue du système au premier lancement ; Préférences ›
  Langue).

### Limites connues
- Pas encore essayé sur de vrais services : e-mail SMTP, passerelle SMS, connexion Google /
  Microsoft, service Windows installé depuis Program Files.
- Les montants gardent la forme `€69.99` en français.
