# Cleis

Internal password manager and contact book for Windows and macOS — personal vault on one computer,
shared spaces through the company server. Rust, GPU-rendered interface (GPUI).

```sh
cargo test --workspace
```

See `CLAUDE.md` (how to work on the project), `docs/DECISIONS.md` and `docs/ETAT.md`.
Mockups: `design/maquettes/index.html?s=01-coffre&theme=dark`.
